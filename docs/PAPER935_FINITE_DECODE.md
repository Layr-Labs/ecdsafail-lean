# Actual finite-depth reverse decoding

The new decoder handles every reachable negative-counter recovery depth at most six, including depths five and six. Its table is the determinant-based modular-inverse bit, defined independently of a walk execution. The proof derives both odd residue addresses from the actual signed physical rows: five bits above the odd low bit of f, and five bits above the odd low bit of the coefficient suffix after the public depth. Signed suffix extraction is proved to equal Euclidean division, including negative values. No externally supplied decoder-correctness or residue witness premise remains in `recoveryLookup_run`.

The actual circuit is two invocations of the existing measured ten-bit lookup with one controlled output flip between them. Both lookups restore their scratch and phase for arbitrary outcomes. It costs 2045 Toffolis and 2044 measurements, with nine lookup scratch wires and one temporary target; support has at most 22 wires including ten address wires, enable, and output. This is an explicit implementation, not the author's optimized decoder gate census. `recoveryLookup_cancel` corrects the pending phase from the earlier branch measurement using its absolute record ordinal.

`DepthResidue` proves that the coefficient equality test on bits one through j recognizes exactly positive valuation j, including signed coefficients and rejecting zero. `HistoryClassFlag` computes that test along with new unfrozen status and nonpositive signed counter, then clears all comparator scratch. `ClassLookup` mints the class flag, invokes the actual lookup, and recomputes/clears the flag. `DepthLookup` binds the complete selected stage to the real old branch bit; an unselected stage leaves the output unchanged. Its hypotheses state actual row encodings, invariant, static wire separation, and clean work. It does not assume the old counter was negative: that is derived on selected lanes.

The composed stage costs 8*zWidth + 2*coefficientSliceWidth + 2053 Toffolis and 8*zWidth + 2*coefficientSliceWidth + 2048 measurements with the current per-bit comparators. This is not a whole-machine peak proof. `FiniteDepth` composes the five actual stages, re-establishing their physical layout, clean-work and row premises from each preceding frame theorem. Their disjoint selectors recover exactly the old branch at depths two through six. One final correction cancels the old measurement phase using its absolute ordinal, after the entire chain. Stored/ramp/swap/frozen recovery integration and reverse arithmetic, width changes, the finite inverse walk, numerical failure bounds and the 935-wire allocation remain outstanding. Ordinary-gate legality and global record legality must also be instantiated for the complete layout.
